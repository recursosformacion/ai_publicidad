Laboratorio de composición publicitaria

Solicita un hueco por tamaño y zona. El servicio calcula las posiciones y devuelve el HTML listo para mostrar.

Solo desarrollo local. Cada petición que devuelve anuncios crea una entrega y contabiliza inmediatamente una impresión por cada anuncio del HTML. Las peticiones de este laboratorio usan la página de prueba ad_layout_lab; no se registra una composición separada.
