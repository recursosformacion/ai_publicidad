Seguridad administrativa

No publicar el panel administrativo en Internet sin autenticación y autorización completas. La documentación del proyecto indica que la autorización administrativa definitiva está pendiente. Mantener el panel y las rutas administrativas en entorno local o red de confianza hasta cerrar esa protección.

El token de servicio es secreto: no debe incluirse en JavaScript público ni entregarse a anunciantes. Los clientes reciben propuestas e informes, no acceso al panel ni a la API administrativa.

Privacidad

Los controles de frecuencia por visitante usan un identificador opaco de primera parte enviado por OSAP y guardan un HMAC del mismo. No enviar correo, ID de cuenta, IP ni otros datos personales. La clave HMAC de producción debe mantenerse privada.

Despliegue de las novedades

La función de paquetes HTML añade la tabla creative_packages mediante la migración Alembic 0005_html_packages. Aplicar las migraciones pendientes antes de utilizarla. Configurar los directorios persistentes AI_PUBLICIDAD_PACKAGE_ROOT y AI_PUBLICIDAD_IMAGE_ROOT, los límites de subida y el origen HTTPS separado AI_PUBLICIDAD_PACKAGE_CONTENT_BASE_URL. No apuntar el origen de paquetes al dominio principal de OSAP. Mantener protegidas las rutas administrativas: la autorización definitiva sigue pendiente.

Conservación del histórico

No borrar ni modificar entregas o eventos para corregir una estadística. Corregir la configuración hacia el futuro y conservar el histórico anterior. Archivar evita nuevas entregas sin destruir la trazabilidad.

Antes de aceptar una campaña

Confirmar que el espacio existe, que el alcance ofrecido se puede servir, que las condiciones están acordadas, que el panel está protegido y que el anunciante entiende qué medimos y qué no.
