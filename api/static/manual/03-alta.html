3. Dar de alta la publicidad

El orden de registro evita mezclar cliente, condiciones, identidad comercial y pieza creativa.

Manual de explotación
Inicio1. Solicitud2. Propuesta3. Alta4. Publicación5. Seguimiento6. Resultados7. Glosario y límites

Orden de trabajo en el panel

  1. Anunciantes: crear cliente; completar nombre, razón social, contacto, correo, teléfono, web y notas.
  2. Pedidos / contratos: asociar al anunciante; definir referencia, estado, moneda, fechas, modelo CPM/CPC/fijo, tarifas, presupuestos y límites.
  3. Marcas y competencia: registrar la marca que aparecerá en el anuncio y sus competidores. Las marcas declaradas competidoras no se colocan juntas en un mismo bloque.
  4. Campañas: crear campaña y asociarla al pedido y marca; definir fechas, estado, prioridad, intervalo mínimo y topes.
  5. Creatividades / anuncios: crear pieza con título, cuerpo, imagen, texto alternativo, idioma, destino, tipo de creatividad y formatos.
  6. Reglas de segmentación: limitar por aplicación, tipo de página, ubicación, idioma, tipo de entidad o ID de entidad.

Qué representa cada registro

Anunciante

Quién contrata y con quién hablamos.

Pedido

Precio, fechas, presupuesto y límites acordados.

Marca

Identidad comercial y conflictos competitivos.

Campaña

Vigencia y reglas operativas de entrega.

Creatividad

Lo que ve el usuario: texto, imagen y enlace.

Reglas

Dónde se permite o prohíbe mostrarla.

Estados que importan

ElementoEstadosCondición para servir
AnuncianteActivo, pausado, archivadoDebe estar activo.
PedidoBorrador, activo, pausado, finalizado, cancelado, archivadoDebe estar activo y vigente.
CampañaBorrador, activa, pausada, finalizada, cancelada, archivadaDebe estar activa y dentro de fechas.
CreatividadBorrador, aprobada, pausada, rechazada, archivadaDebe estar aprobada.

Preparar el material

  • Las creatividades de tipo imagen o imagen+texto necesitan URL de imagen.
  • Toda imagen necesita texto alternativo (ALT).
  • El destino debe ser una URL HTTP(S) válida y revisada.
  • Asociar solo formatos que el material pueda ocupar sin deformarse.
  • El HTML de salida lo genera el servicio; no introducir scripts ni HTML libre del anunciante.

Segmentación

Las reglas admiten aplicación, tipo de página, ubicación, idioma, tipo de entidad e ID de entidad. Varias inclusiones del mismo campo son alternativas; las exclusiones prevalecen si coinciden. Ejemplo: incluir fichas de obra y excluir una ubicación concreta.

Consejo: empezar con una segmentación sencilla y ampliarla solo cuando haya una razón comercial. Demasiadas restricciones pueden dejar la creatividad sin ningún espacio elegible.
