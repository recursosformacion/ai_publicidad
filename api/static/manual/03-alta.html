3. Dar de alta la publicidad

El orden de registro evita mezclar cliente, condiciones, identidad comercial y pieza creativa.

Orden de trabajo en el panel

  1. Anunciantes: crear cliente; completar nombre, razón social, contacto, correo, teléfono, web y notas.
  2. Pedidos / contratos: asociar al anunciante; definir referencia, estado, moneda, fechas, modelo CPM/CPC/fijo, tarifas, presupuestos y límites.
  3. Marcas y competencia: registrar la marca que aparecerá en el anuncio y sus competidores. Las marcas declaradas competidoras no se colocan juntas en un mismo bloque.
  4. Campañas: crear campaña y asociarla al pedido y marca; definir fechas, estado, prioridad, intervalo mínimo y topes.
  5. Creatividades / anuncios: crear pieza con título, cuerpo, imagen, texto alternativo, idioma, destino, tipo de creatividad y formatos. Para HTML estático, elegir HTML (ZIP).
  6. Reglas de segmentación: limitar por aplicación, tipo de página, ubicación, idioma, tipo de entidad o ID de entidad.

Qué representa cada registro

Anunciante

Quién contrata y con quién hablamos.

Pedido

Precio, fechas, presupuesto y límites acordados.

Marca

Identidad comercial y conflictos competitivos.

Campaña

Vigencia y reglas operativas de entrega.

Creatividad

Lo que ve el usuario: texto, imagen, enlace o un paquete HTML estático aislado.

Reglas

Dónde se permite o prohíbe mostrarla.

Preparar el material

Imagen convencional

  1. Crear la creatividad con tipo Imagen, Imagen y texto o Adaptable.
  2. Completar el texto alternativo (ALT) y guardar la creatividad.
  3. Volver a abrirla, seleccionar la imagen y pulsar Subir imagen. El panel asocia automáticamente la versión optimizada.

Se admiten JPEG/JFIF, PNG y WebP en el panel. El servicio limita la subida a 5 MB por defecto y reduce las dimensiones máximas a 2000 píxeles (configurable). Las imágenes estáticas se convierten a WebP; PNG y transparencias se conservan sin pérdida. Los GIF y WebP animados se conservan con sus fotogramas. La calidad WebP predeterminada es 88. La optimización no puede recuperar detalle que ya se perdió en la imagen original.

Creatividad HTML (ZIP)

  1. Crear una creatividad y elegir HTML (ZIP); guardar primero el registro.
  2. Preparar un ZIP con index.html en la raíz y todos los recursos necesarios dentro del paquete.
  3. Volver a abrir la creatividad, seleccionar el ZIP y pulsar Subir paquete.
  4. Asociar los formatos publicitarios que correspondan y revisar la pieza antes de aprobarla.

El paquete admite HTML, CSS, imágenes y fuentes estáticas. No admite JavaScript, ficheros ejecutables, enlaces simbólicos, rutas que salgan del paquete ni ZIP cifrados. Los límites predeterminados son 2 MB comprimidos, 10 MB descomprimidos y 100 ficheros. Las hojas de estilo y recursos deben estar incluidos en el ZIP; la política de seguridad bloquea scripts y recursos externos.

El anuncio se muestra dentro de un iframe aislado, con sandbox y política CSP, y no se inserta como HTML libre en la página de OSAP. El clic se registra mediante la capa de seguimiento del servicio. En producción, el contenido debe servirse desde un origen HTTPS separado del sitio y de la aplicación administrativa; configurar AI_PUBLICIDAD_PACKAGE_CONTENT_BASE_URL y AI_PUBLICIDAD_PACKAGE_FRAME_ANCESTORS.

Para ambos tipos

  • El destino debe ser una URL HTTP(S) válida y revisada.
  • Asociar solo formatos que el material pueda ocupar sin deformarse.
  • Guardar primero la creatividad: las subidas se vinculan a un registro ya creado.

Segmentación

Las reglas admiten aplicación, tipo de página, ubicación, idioma, tipo de entidad e ID de entidad. Varias inclusiones del mismo campo son alternativas; las exclusiones prevalecen si coinciden. Ejemplo: incluir fichas de obra y excluir una ubicación concreta.

Consejo: empezar con una segmentación sencilla y ampliarla solo cuando haya una razón comercial. Demasiadas restricciones pueden dejar la creatividad sin ningún espacio elegible.
