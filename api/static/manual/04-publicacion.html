4. Revisar, activar y comprobar

La configuración no equivale a publicación: hay que comprobar la elegibilidad y el sitio real.

Lista previa a la activación

  • Anunciante activo y datos correctos.
  • Pedido activo, vigente y con condiciones pactadas.
  • Campaña vinculada al pedido y marca correctos.
  • Fechas, presupuesto y topes coherentes.
  • Creatividad aprobada, idioma correcto y destino revisado.
  • Imagen accesible y ALT informado, si procede.
  • Formatos compatibles con el material y el espacio.
  • Reglas de segmentación correctas.
  • Competidores registrados correctamente.

Cómo selecciona el servicio

  1. Comprueba estados y fechas de campaña, creatividad, pedido y anunciante.
  2. Aplica presupuestos, límites, pacing y frecuencia.
  3. Comprueba idioma, segmentación, marca activa, competencia e intervalo de repetición.
  4. Solo después calcula el formato y la composición que caben.
  5. En composición automática prueba primero el tamaño mayor que encaja; un bloque no mezcla tamaños.
  6. Evita repetir campaña o marca y evita marcas competidoras juntas.
  7. Si no hay anuncio comercial compatible, puede servir publicidad propia de OSAP como reserva.

Comprobar en la web

Probar las páginas contratadas, en los idiomas y dispositivos acordados. Revisar carga de imagen, proporción, legibilidad, enlace de destino, ubicación, ausencia de competidores y frecuencia razonable.

Integración aún por validar: el repositorio indica que el cliente real de OSAP y la integración del frontend requieren validación. El panel de ai_publicidad no demuestra por sí solo que el anuncio aparezca en todas las páginas. No marcar como publicada hasta probar el sitio desplegado.

Si no aparece

Revisar estados, fechas, idioma, formatos, dispositivo, segmentación, marca, límites, presupuesto, pacing y frecuencia. Después comprobar que OSAP envía el tipo de página y ubicación esperados y que la llamada al servicio funciona. Que no haya anuncio comercial puede ser un resultado normal si no existe creatividad elegible; el sistema contempla el anuncio propio de reserva.
